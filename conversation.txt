SILICON SWITCH LAB: PROJECT RATIONALE
=====================================

Silicon Switch Lab is a general-purpose learning and portfolio project for
networking, distributed systems, hardware-aware software, and performance
engineering roles. It is intentionally independent of any employer or
proprietary network-silicon product.

The project combines a portable C++17 software switch/router, a SAI-inspired
vendor-neutral control interface, Python orchestration, an authoritative
CPU/CUDA simulation, and synchronized OpenGL observers. The target lab uses one
RTX 3080 Linux desktop, one Linux laptop, and two Windows laptops, while all
correctness-critical components remain testable on a single computer.

The technical scope includes Ethernet, VLANs, MAC learning, ARP, IPv4 routing,
longest-prefix matching, next hops, queues, congestion, counters, fault
injection, state reconciliation, versioned protocols, synchronization,
cross-platform builds, testing, profiling, and recovery.

The project may support preparation for many positions, including network
systems, embedded or hardware-facing C++, distributed infrastructure, HPC,
GPU/CUDA, visualization, reliability, and performance engineering. Employer-
specific interview notes should remain outside the core product documentation.
